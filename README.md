# VIP Magical Physio Clinic

Open the website and manage this project using these permanent links:

- [Live website](https://vipmagicalphysio.netlify.app/)
- [Netlify project dashboard](https://app.netlify.com/projects/vipmagicalphysio) — sign in with an authorised Netlify account.
- [Clinic dashboard](https://vipmagicalphysio.netlify.app/staff-dashboard.html) — requires a clinic account with the admin or staff role.
- [Patient dashboard](https://vipmagicalphysio.netlify.app/dashboard.html)
- [Source repository](https://github.com/ahirevipul1994-bit/vipmagicalphysio)

The clinic dashboard also includes buttons for opening the live website and Netlify project.

Public website files are in `public/`. Server code is in `netlify/server/`, and database definitions are in `db/`. Run `npm test` to check application policies and published page links.
